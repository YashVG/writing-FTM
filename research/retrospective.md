# Retrospective

The strongest engineering lesson was that syntactic success looked like semantic success. The first critique returned valid JSON and real quotes but approved an unsupported causal claim. A follow-up prompt separated passage from source; the model then recognized the causal wording yet rationalized retaining it. The observed failure was therefore broader than input confusion: the decision rule accepted plausible claims without adequate support.

We tested an explicit evidence-support standard against the previous prompt on paired development inputs, then froze it for reserved evaluation. Saved failures remain in the repository. Full outputs reveal shortcomings that verdict scores miss, including invented confidence levels and generic issue diagnoses.

The presentation design deliberately limits flexibility: framing and ordering change while substantive fields stay fixed. This provides a testable baseline. It does not show that users perceive more warmth, and it does not address all semantic drift caused by free-form rewriting.

Next research steps are independent human review, new held-out sources after this release, and a comparison against generative tone rewriting. Style-example retrieval and training depend on reliable labels. This is a solo, AI-assisted project; automated tests and assistant review do not substitute for human collaboration or independent replication.
